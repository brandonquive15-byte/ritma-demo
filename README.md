# Ritma — demo privada

Landing + demo funcional de agenda para salones, barberías, uñas y spas.

Esta página está **cifrada** (AES-256-GCM con clave derivada por PBKDF2-SHA256).
El HTML del producto no existe en el código fuente de esta publicación: se
descifra en el navegador cuando el usuario y la contraseña son correctos.

- Sin backend, sin cookies, sin rastreo.
- Cada recarga vuelve a pedir el acceso.
- Los datos de la demo (citas, cobros, reservas) se guardan solo en el navegador
  de quien la usa, con `localStorage`. Nadie más los ve.

Demo de producto. Las marcas, precios y textos son propios; no hay afiliación
con otras plataformas del sector.
